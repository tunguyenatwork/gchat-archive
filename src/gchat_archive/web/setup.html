Connect Google

The archive talks to Google Chat with your own OAuth client. Upload it once — it stays on this machine.

1 · Upload client_secret.json

2 · How to get the file

  1. Open Google Cloud Console → create a project (any name).
  2. Enable both APIs in Google Chat API and Google Drive API.
  3. OAuth consent screen → External → add your own address under Test users → save. Add the scopes chat.messages, chat.spaces.readonly, drive, gmail.readonly.
  4. Credentials → Create credentials → OAuth client ID → application type Desktop app → create.
  5. Click Download JSON and upload that file here.

Free, no billing account. In “Testing” mode Google expires the token after 7 days — re-run sign-in then, or publish the app.
